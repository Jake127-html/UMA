# UMA - A Universal Measurement Application [WIP]

## **Tired of Googling to convert units?** 

This lightweight python application exists as an instant and easily viewable GUI to convert units of varying types effortlessly. No more opening a browser and hoping to find the right converter. 

If you were to try any popular search engine right now, there is NO option to quickly convert pixels to inches. If you have a niche need for unit conversion, or don't want to use extra resources while working this app is perfect for you!
  
## Coded in

Python using CustomTkinter, and  [to be] compiled via AutoPy
