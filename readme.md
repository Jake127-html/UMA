# UMA - A Universal Measurement Application [WIP]

## **Tired of Googling to convert units?** 

This lightweight python application exists as an instant and easily viewable GUI to convert units of varying types effortlessly. No more opening a browser and hoping to find the right converter. 

# Pre-requisites  
None. 
  
# Installation Guide  
1. Download the .zip  
2. Unzip  
3. Open, launch via UMA shortcut.  
4. Enjoy.
